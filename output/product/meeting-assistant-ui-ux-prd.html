Product UI/UX PRD

本地 macOS 会议助手的完整体验蓝图

这份 HTML 文档把项目事实源整理成类似 Figma 产出物的 PRD：覆盖产品定位、用户旅程、核心功能介绍、关键 UI 状态、桌面画板、设计 token、验证状态和未决边界。

Primary user 本地会议记录用户

在自己的 Apple Silicon Mac 上独立录制会议、生成 transcript、回查、导出，并自行决定是否粘贴到外部 GPT。

MVP surface 最小 Swift/SwiftUI app + processing CLI

图形入口负责录制控制和可见状态，CLI/helper 负责依赖检查、媒体处理、转写、speaker label fallback、导出和删除。

Scope

产品范围、设计原则和非目标

本文档只整理既有事实源，不新增产品能力。任何自动纪要、团队共享、商业分发、辅助录制主路径或真实身份识别，都必须先走 spec-change、ADR 和验证矩阵更新。

source-derived
North Star 本地记录和可回查

用户能完成录制前检查、开始/停止原生录制、保存视频和音频、生成带时间戳 transcript，并在本地回查。

Privacy boundary 默认不上传

会议视频、音频、transcript 和日志默认保留在本地 workspace。外部 GPT 仅是用户主动复制或导出后的外部行为。

MVP truth best-effort 匿名标签

speaker labels 用 `SPEAKER_01` 等匿名标签辅助阅读，不代表真实姓名，也不承诺 diarization 质量阈值。

设计原则

UI/UX
状态先于装饰权限、依赖、录制、处理、降级、失败和删除结果必须可见、可查询、可恢复。
文件化和可重试原始媒体优先保护，normalized audio、transcript、speaker labels 和 export 都是可重建派生产物。
主动外部使用复制或导出 transcript 是用户触发动作，界面不暗示自动纪要或自动上传。

明确非目标

out of MVP
团队账号和共享会议库多人使用时仍各自在本机独立运行，不提供组织空间、集中审计或团队支持。
自动 GPT / Qwen 纪要当前是 watch 决策；进入实现前必须新增 API、安全、数据和验证覆盖。
OBS / BlackHole 主路径原生 macOS 录制优先；辅助方案只能在 spike 证据后通过 spec-change 纳入。

planned UI
Happy path

Preflight ready → native recording → artifacts available → transcript generated → export markdown → delete session later.

Degraded path

系统音频或 speaker engine 不可用时，界面保留成功产物并明确显示 `degradation_reason`。

Recovery path

依赖缺失、模型缺失、导出路径冲突、路径越界和处理失败都必须返回可解释错误，并保留原始媒体。

Capability Catalog

基础功能介绍和用户价值

这部分可以作为面向用户或评审者的产品说明。验证状态取自当前矩阵：`covered` 才代表长期标准门禁完整覆盖；`partial/planned` 只能代表能力目标或局部证据。

CAP-MA-001..012
01权限和环境预检

开始录制或处理前暴露权限、依赖、模型、workspace 和允许来源状态。

02原生录制控制

SwiftUI 最小窗口提供开始、录制中、停止、保存和失败反馈。

03会话和产物登记

每次会议落盘为 `MeetingSession`，可追踪视频、音频、metadata 和降级原因。

04导入已有媒体

用户显式选择 `.wav/.m4a/.mp3/.mp4/.mov` 文件，作为回退或测试入口。

05标准化音频

从可用音频生成可重建 `.wav`，不覆盖原始录制音轨。

06时间戳转写

本地 `whisper.cpp` 或 fake adapter 生成按时间排序的 transcript segments。

07匿名 speaker labels

输出 `SPEAKER_01` 等辅助标签；不可用时 transcript-only fallback。

08回查与导出

用户查看时间戳、复制或导出 plain text / Markdown / JSON，不自动上传。

09删除本地会话

用户确认后删除当前 workspace 内会话目录，workspace 外导出文件保留。

10本地数据边界

默认 workspace 是 `~/Movies/MeetingAssistant/`，MVP 不提供应用级加密。

11模块解耦

native app、helper、processing CLI、workspace files 和 adapter 通过契约协作。

12可验证门禁

每个能力必须回指 `AC-MA-*`、`PV-MA-*` 和标准脚本证据。

Voice rule

按钮和状态命名用明确对象，例如 “Start Native Recording”、“Export Markdown”、“Delete Session”。避免 “OK”、“Confirm” 或不带对象的裸动词。
